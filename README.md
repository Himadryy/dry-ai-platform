# DRY AI Platform (Don't Repeat Yourself)

A Modular Enterprise AI Platform. A highly secure, air-gapped core backend engine with industry-specific portals (Healthcare, Legal, Logistics, DevOps) built on top.

## Tech Stack
- Python, FastAPI
- Async SQLAlchemy, PostgreSQL
- Qdrant, Ollama, Haystack
- Microsoft Presidio
- Docker Compose

## Core Concept
Solve the massive enterprise problem of Data Sovereignty and GDPR compliance by anonymizing PII before AI processing.
